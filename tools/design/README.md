# Editorial theme

Independent adaptation of the editorial layout at https://microsoft.ai/blog/.
The existing Hexo/NexT renderer is retained so published routes, page content,
mathematical markup, and PDF links keep their existing addresses.

Visual changes live in the global shell and `source/css/editorial.css`.
`source/js/editorial.js` supplies site search, theme choice, mobile navigation, and the reading outline.
The personal homepage is retained at `/`; the editorial blog lives at `/blog/`.
The blog shows four curated series entry points and three standalone articles.
Individual lessons remain in their existing course directory and are excluded
from the global search index. Private research notes are not imported.
The original profile, research, publication and CV content is preserved.

Original mathematical cover illustrations are generated by `create_covers.py`
with Python, NumPy, Matplotlib, and Pillow. No Microsoft images, fonts, logos,
or other brand assets are redistributed. Serif typography follows the explicitly
requested publication reference; controls use the system sans font.

Design audit: replaced the former grey background, white boxes, left navigation,
and complete posts on the homepage. Retained the wordmark, original page routes,
article text, categories, legal notices, math renderer, and resource downloads.
Design variance 6, motion intensity 3, visual density 3. Native CSS is used for
this publication aesthetic; it is not presented as a Fluent UI implementation.

Validation: clean Hexo build, JavaScript syntax and whitespace checks; local
links on homepage, blog, collections and course-note pages resolve. Checked
390px mobile, 900px tablet, desktop, light/dark appearance, and 308 rendered
MathJax expressions on session 10 with no math errors. Local Lighthouse on the
restored homepage: performance 98, accessibility 100, SEO 100. Best practices 81
includes the expected HTTP-only local-preview warning; production uses HTTPS.
